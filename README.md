# Skills

Skills for Claude, shared by LFG Solutions.

| Skill | What it does |
|---|---|
| [brainstorm](brainstorm) | Turns a messy burst of ideas into an interactive brainstorm page, improves it round after round, then makes it the official version (roadmap, presentation or project map). |

## Install

**Claude Code** (with the skills CLI):

```bash
npx skills add lfgsolutions/skills@brainstorm
```

Or copy the `brainstorm` folder to `~/.claude/skills/brainstorm/`.

**Claude app or claude.ai**: download `brainstorm.zip` from the [latest release](https://github.com/lfgsolutions/skills/releases/latest), then upload it in Settings, Capabilities, Skills.

Each skill folder has its own README with details and requirements.
